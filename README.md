# 🔢 Decimal to Binary API

API REST desenvolvida em Node.js e Express para conversão de números decimais em representações binárias, contendo validação de parâmetros, testes automatizados e documentação interativa com Swagger UI.

---

## 🚀 Tecnologias Utilizadas

* **Node.js** & **Express** - Construção do servidor e rotas da API
* **Jest** & **Supertest** - Testes de integração automatizados
* **Swagger UI** & **YAMLJS** - Documentação OpenAPI interativa
